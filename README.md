    Data Science Practice Repository

Welcome to my Data Science Practice Repository 👋

I have recently completed my Data Science course and created this repository to practice and showcase my Python programming skills.
This repo contains beginner-friendly Python scripts that demonstrate concepts in Object-Oriented Programming (OOP) and core Data Science libraries like NumPy, Pandas, and Matplotlib.

The aim of this repository is to build a strong foundation, while I continue to expand with advanced projects in Data Science & Machine Learning.

📂 Repository Contents
🐍 Python Concepts & Data Science Libraries

Inheritance (inheritancee.py)

Demonstrates how an object can access attributes of another object in another class using Inheritance in Python.

Data Visualization (matplotlibb.py)

Uses the Matplotlib library for creating simple and effective data visualizations.

NumPy Arrays (numpyy.py)

Showcases NumPy for creating and manipulating arrays efficiently.

Data Manipulation (pandass.py)

Uses the Pandas library for handling and analyzing structured datasets.

Polymorphism (polymorphism.py)

Explains the Polymorphism concept in OOP, showing different behaviors of methods in different instances.
